# 障害管理運用の流れ

## ■ バグ管理運用

1. **テスト担当者バグ票起票（水田さん）**（バグ管理番号付与）  
   └──> 2. **バグ対応者（趙さん）割り当て**  
       └──> 3. **Mainブランチから修正用ブランチ作成（バグ管理番号毎）**  
           └──> 4. **バグ修正**  
               └──> 5. **GitでPull Request作成**  
                   └──> 6. **修正内容レビュー依頼（竇）**  
                       ├── **指摘あり** → 7. **バグ再修正** → 6. **再レビュー依頼へ**  
                       │  
                       └── **指摘なし** → 8. **Mainブランチへマージ**（レビュア：竇、趙実施）  

---

## ■ デプロイ運用

- **デプロイ（通常）**：翌朝（朝会後）前日マージ分をテスト環境へ反映  
- **デプロイ（緊急）**：システム全体影響が大きい修正※について、Mainブランチマージ後即時テスト環境反映  

※ テスト環境に反映しないと、次画面遷移や次の処理が進めない場合  

- **デプロイは全員が対応できるように当番制を導入**
